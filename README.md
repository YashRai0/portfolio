# Yash Rai — Portfolio

Personal portfolio website built with React, TanStack Start, and Tailwind CSS.

**Live:** https://yashrai0.github.io/portfolio/

## Tech Stack

- **Framework:** TanStack Start (React + TypeScript)
- **Styling:** Tailwind CSS + custom CSS
- **Backend:** TanStack server functions
- **Database:** Supabase (with mockData fallback)
- **AI Chat:** Anthropic Claude API / Gemini fallback
- **Deploy:** Vercel / GitHub Pages

## Projects Featured

- **Resume Optimizer** — Live ATS resume analyzer → [resumeai4u.vercel.app](https://resumeai4u.vercel.app/)
- **AI Study Assistant** — RAG-powered PDF study tool (in progress)

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
ANTHROPIC_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here        # fallback
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key
```
